## Ce que j'ai codé
- le script lru_cache.py ce script implémente un cache LRU (Least Recently Used) permettant de stocker temporairement des données pour éviter de recalculer plusieurs fois les mêmes résultats. Il utilise un dictionnaire et une liste doublement chaînée afin d'assurer des opérations de lecture et d'écriture rapides en temps constant O(1). Le script inclut également un décorateur permettant d'ajouter automatiquement ce mécanisme de cache à une fonction, ce qui améliore ses performances, notamment pour le calcul récursif de Fibonacci.
- le script test_lru_cache.py ce script contient une série de tests unitaires réalisés avec Pytest afin de vérifier le bon fonctionnement du cache LRU. Les tests contrôlent les opérations de base (get et put), la suppression de l'élément le moins récemment utilisé lorsque le cache est plein, la mise à jour d'une clé existante, les performances des opérations en temps constant O(1) ainsi que le bon fonctionnement du décorateur appliqué au calcul de la suite de Fibonacci.

## Ce qui m'a bloqué
 J'ai eu un blocage au niveau de `pytest` lors des imports :
 D'abord une erreur de syntaxe à cause du tiret dans le nom de fichier lru-cache.py résolue en le renommant en lru_cache.py.
J'ai également rencontré une erreur ModuleNotFoundError, indiquant que Python ne parvenait pas à trouver le module lru_cache lors de l'exécution des tests. Ce problème était lié à la manière dont les tests étaient lancés. Pour le résoudre, j'ai exécuté les tests avec la commande python3 -m pytest tests/test_lru_cache.py -v, ce qui permet à Python d'utiliser correctement le répertoire du projet et de retrouver le module à importer. Après cette modification, les tests se sont exécutés sans problème.
Lors des tests, j'ai rencontré une erreur NameError: name 'node' is not defined dans la méthode put() du cache. Cette erreur se produisait lors de la mise à jour d'une clé déjà présente dans le cache, car j'essayais de modifier la variable node sans l'avoir récupérée au préalable. Pour corriger ce problème, j'ai ajouté la ligne node = self.cache[key], qui permet de récupérer le nœud correspondant à la clé avant de mettre à jour sa valeur et de le déplacer en tête de la liste. Cette correction a permis d'éliminer l'erreur et de rétablir le bon fonctionnement de la méthode put().
