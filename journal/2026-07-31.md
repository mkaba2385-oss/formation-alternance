**Date** : 2026-07-31

**Durée effective** : 4h30

## Ce que j’ai appris

* J'ai compris la différence entre un module (un fichier `.py`) et un package (un dossier contenant un fichier `__init__.py`).
* J'ai appris à organiser un projet Python avec une structure moderne en utilisant un dossier `src/`.
* J'ai utilisé différents types d'imports (`import`, `from ... import` et les imports relatifs).
* J'ai compris le rôle du fichier `__init__.py` et de la variable `__all__`.
* J'ai appris à utiliser le bloc `if __name__ == "__main__":` pour faire la différence entre un script exécutable et un module importable.
* J'ai compris le rôle du fichier `pyproject.toml` dans un projet Python moderne.
* J'ai appris à installer un package en mode éditable avec `pip install -e .`.
* J'ai compris ce qu'est un import circulaire et comment le corriger en améliorant l'organisation du projet.
* J'ai appris à créer une couche de service en mémoire avant l'utilisation d'une base de données.
* J'ai créé des exceptions personnalisées pour gérer les erreurs de la couche service.
* J'ai utilisé un décorateur pour mesurer le temps d'exécution des méthodes.
* J'ai manipulé les modèles Pydantic avec `model_dump()` et `exclude_unset=True`.
* J'ai créé un CRUD en mémoire en utilisant un dictionnaire Python.
* J'ai utilisé un générateur (`yield`) pour retourner les parcelles d'un propriétaire.
* J'ai utilisé des compréhensions de listes pour filtrer les parcelles selon plusieurs critères.
* J'ai écrit des tests unitaires avec `pytest`, en utilisant les fixtures, `pytest.raises` et `pytest.mark.parametrize`.

## Ce que j'ai codé

### Exercices sur les modules et les packages

* **utils.py** : contient les fonctions `chunk`, `retry` et `format_fcfa` du package `mesutils`.
* ****init**.py (mesutils)** : exporte les fonctions principales du package et définit sa version.
* **test_utils.py** : teste les fonctions `chunk` et `format_fcfa`.
* **demo.py** : montre comment utiliser le package `mesutils` dans un autre projet.
* **users.py** : gère la création d'un utilisateur et lance la création d'une commande.
* **orders.py** : crée une commande puis envoie une notification.
* **notifications.py** : envoie une notification à l'utilisateur.
* **models.py** : contient la classe `User` pour supprimer les imports circulaires.
* **main.py** : lance un scénario de test pour vérifier que le projet fonctionne correctement après la correction des imports circulaires.

### Projet Sini

* **services/exceptions.py** : création des exceptions `SiniServiceError` et `EntityNotFoundError`.
* **services/utils.py** : création du décorateur `timer` pour mesurer les performances des méthodes de service.
* **services/parcelle_service.py** : développement d'un service en mémoire permettant de créer, consulter, modifier, supprimer et filtrer les parcelles.
* **services/**init**.py** : export des classes et exceptions principales du package.
* **tests/conftest.py** : création d'une fixture `pytest` pour fournir une instance propre du service à chaque test.
* **tests/test_parcelle_service.py** : écriture des tests unitaires du service des parcelles.
* **tests/test_schemas.py** : écriture des tests de validation des schémas Pydantic.
* **pyproject.toml** : configuration des dépendances, de `pytest`, `pytest-cov` et `mypy`.
