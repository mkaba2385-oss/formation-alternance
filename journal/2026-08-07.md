# Jour 20 – Pydantic : validation des données

**Date :** 07/08/2026

**Durée effective :** 4h00

## Ce que j’ai appris

Aujourd'hui, j'ai découvert comment utiliser **Pydantic v2** pour valider les données dans une application Python. J'ai compris qu'il permet de vérifier automatiquement les informations reçues et de convertir certains types de données lorsque c'est nécessaire.

J'ai également appris à créer des types de données personnalisés avec `Annotated`, `Field` et des validateurs afin d'imposer des règles précises, par exemple pour les numéros de téléphone, les montants ou les coordonnées GPS.

J'ai compris le fonctionnement des validations entre plusieurs champs grâce à `@model_validator(mode="after")`. Cela permet de vérifier que plusieurs informations sont cohérentes entre elles après la validation du modèle.

J'ai aussi vu comment gérer les erreurs lors de l'import d'un fichier CSV. Au lieu d'arrêter le programme dès qu'une ligne est incorrecte, il est possible de récupérer les erreurs, d'ignorer les lignes invalides et de générer un rapport des problèmes rencontrés.

Enfin, j'ai découvert l'utilisation de **pydantic-settings** pour gérer la configuration de l'application selon les différents environnements (développement, test et production).

---

## Ce que j'ai codé

### `src/sini/schemas/journal.py`

J'ai complété le schéma du journal agricole en ajoutant `JournalEntryUpdate`, qui permet de modifier uniquement les champs nécessaires lors d'une mise à jour.

### `src/sini/schemas/diagnostic.py`

J'ai ajouté le modèle `PredictionItem` pour gérer les données du champ `predictions` ainsi que `DiagnosticUpdate` pour faciliter la mise à jour des diagnostics.

### `src/sini/schemas/__init__.py`

J'ai mis à jour les exports du dossier des schémas afin de rendre accessibles les nouveaux modèles créés.

### types.py`

J'ai créé plusieurs types personnalisés pour éviter de répéter les mêmes validations dans le projet :

* validation des numéros de téléphone maliens ;
* validation des montants en FCFA ;
* validation du nom d'une parcelle ;
* validation des coordonnées GPS situées au Mali.

### alerte.py`

J'ai créé le schéma `AlerteRequest` avec une validation qui vérifie les informations en fonction du type d'alerte demandé.

### csv_importer.py`

J'ai développé un module permettant d'importer un fichier CSV contenant les prix agricoles. Le programme lit chaque ligne, signale les erreurs rencontrées et continue l'import des lignes valides.

### config.py`

J'ai mis en place la configuration de l'application avec **pydantic-settings** afin d'adapter automatiquement les paramètres selon l'environnement utilisé.
