## Ce que j’ai appris
- J’ai appris à utiliser la méthode TDD en suivant les différentes étapes : commencer par écrire un test qui échoue ensuite faire le code nécessaire pour que le test fonctionne puis améliorer le code sans casser les tests déjà faits.    

- J’ai appris à utiliser pytest-cov pour voir quelles parties du code sont réellement couvertes par les tests.     

- J’ai appris qu’il y a certaines erreurs à éviter quand on fait des tests. Exemple :  un test ne doit pas dépendre d’un autre test il ne faut pas utiliser des mocks partout tant que tu en a pas besoin et il faut bien nettoyer les fixtures après les tests pour ne pas avoir des problèmes avec les tests suivants.
