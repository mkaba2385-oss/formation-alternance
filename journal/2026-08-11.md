## Ce que j’ai appris
- Mettre les fixtures dans **conftest.py** pour pouvoir les utiliser dans toute la suite de tests sans avoir besoin de faire des imports à chaque fois.  

- **Paramétrisation (@pytest.mark.parametrize)** : Tester plusieurs données, avec des cas valides et invalides, sur une même fonction. Utiliser des ids clairs pour pouvoir facilement voir quel cas a échoué avec pytest -v.

- **Mocks et Patchs (unittest.mock)** : Faire des tests sans utiliser les vrais services externes. Par exemple, on peut simuler l’envoi d’un SMS ou la génération d’un code OTP avec @patch et create=True.

- **Property-based testing** : Utiliser la librairie Hypothesis avec @given et strategies pour créer automatiquement plusieurs cas de test.


## Ce que j'ai codé

- **test_schemas_refactor.py** : Dans ce script j’ai utilisé @pytest.mark.parametrize pour éviter de refaire plusieurs fois le même test. Le but est de tester la validation des numéros de téléphone avec plusieurs exemples différents. J’ai mis 10 numéros valides et 10 numéros invalides. J’ai aussi ajouté des id pour chaque cas afin de savoir facilement quel numéro a causé une erreur quand un test échoue.   

- **test_service.py** : Dans ce script j’ai fait un test complet du parcours d’authentification de Sini sans utiliser de vrais services externes. Le test commence par la demande d’un code OTP puis vérifie le code pour obtenir un JWT et utilise ensuite ce JWT pour accéder aux parcelles. J’ai mocké le SMS gateway la génération du code OTP et l’horloge pour pouvoir contrôler les différents cas pendant les tests. J’ai aussi ajouté des tests pour vérifier les erreurs comme un mauvais code OTP un OTP expiré et un JWT falsifié. J’ai utilisé Hypothesis pour tester automatiquement différents formats de numéros de téléphone du Mali.  


## Ce qui m'a bloqué
- **Dépendances manquantes (ModuleNotFoundError)** : Au début le test ne fonctionnait pas parce que le module hypothesis n’était pas installé dans l’environnement virtuel .venv. J’ai réglé le problème en installant le module avec la commande pip install hypothesis.

- **Erreur AttributeError avec le mock** : Au début le test avait une erreur parce que la fonction send_sms n’était pas trouvée dans le module sms.py avec le nom utilisé dans le patch. J’ai réglé le problème en ajoutant create=True dans le décorateur @patch ce qui a permis de faire le mock même si l’attribut n’existe pas directement dans le module.
