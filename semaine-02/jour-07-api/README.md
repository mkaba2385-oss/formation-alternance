# scripts météo  
Un script Python simple pour consulter la météo d'une ville via l'API OpenWeatherMap.
## Comment lancer le script  
###  Définir la clé API  
Avant de démarrer, tu dois exporter ta clé OpenWeatherMap dans une variable d'environnement :  
export OPENWEATHER_API_KEY="ta_cle_api_ici"  

### Lance le script en spécifiant le nom de la ville en argument

Python3 scripts/meteo.py paris
