# Mini-Rapport

## ce que j'ai ressenti
Au début l'exercice demande une certaine rigueur. Il faut d’abord écrire le test avant de faire la fonction donc ça oblige à bien réfléchir à comment la fonction va fonctionner. Quand je voit ensuite le test passer du rouge au vert jai été satisfait.

## ce qui a été dur
J’ai eu quelques problèmes avec l’organisation du code surtout avec des imports circulaires entre les différents modules. Il a fallu que je reprenne un peu la structure pour régler ça.

## ce qui a été utile
Ce que j’ai trouvé utile avec les tests c’est qu’on voit assez vite ce qui est couvert dans le code. Ça permet aussi de tester des cas auxquels on ne pense pas forcément, comme une liste vide
